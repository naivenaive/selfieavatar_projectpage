SelfieAvatar project webpage

Deploy all contents of this folder to the root of your GitHub Pages publishing branch (or selected /docs folder), keeping subfolders intact.
Set GitHub repository Settings > Pages > Deploy from a branch, then select that branch and folder.
The entry point is index.html. No build or installation is required.
All images, videos and the full-paper PDF are included locally. Original Inter and Orbitron fonts are bundled in assets/fonts, with no external font requests.
